# 两个参考方向与规划边界

后续版本将0.1.6的53个地图入口精简为46个站区入口。每个站区仅展示参考方向A/B与去重后的线路标签，替代逐条展开的原始停靠记录。103条源站点身份、162次线路经过与轨迹文件全部保留。

展示归拢要求同名、组内任意两点不超过80米，仅白名单兼容“共青花园2号门／共青团花园2号门”。不同楼号、较远同名站不合并。展示锚点取已有坐标，不生成道路两侧站位，也不据此合并规划换乘节点。

方向依据停靠投影处的局部轨迹轴对齐；不同线路正序不直接当成同向。邻接段急转／折返、退化段、近垂直分岔不自动归类，显示方向待核对并可查看线路或自动规划。2号门3／6号线的折返段已列入回归。A/B是发布轨迹参考顺序，不能证明实际运营方向或物理站台位置。

选择参考方向后，规划仅允许对应线路、经过索引及参考顺序：直达同时约束上下车，换乘约束第一腿上车与最后一腿下车。过滤发生在最近六个候选截断前，重复经过按原索引区分；隔离点仍不能乘降。修改一个端点只清除该端点限制，交换位置同步交换限制。普通地点、定位与自动规划保持原有行为。

验证结果：

- 安装、数据同步、数据校验、TypeScript及完整覆盖率运行通过，339项测试通过。
- 微信开发者工具在同一候选上完成16组回归：十条线的地图与站序、全部46个站区、方向选择、直达、换乘、方案恢复、模糊搜索、数字保护、无坐标地点、地图选点及短屏布局。
- 定位拒绝、成功、低精度、非法／范围外坐标，以及腾讯选点非法返回／成功均为开发工具会话内合成输入；测试结束恢复模拟API，未操作真实用户授权。
- 腾讯接口真实开通状态、手机体验版GPS／地图行为和微信审核结果未由这些模拟器用例验证，不把代码通过等同于平台验收。
- 独立复核提出的折返误分类已修复并回归，最终未发现其他实质问题。未新增依赖、付费地图请求、真实定位采集或实时车辆接入。

0.1.6为此前已上传基线；本次界面变更须上传后续版本。公开仓库保持游客配置，正式候选及截图仅保存在本机，上传前继续检查脱敏。
