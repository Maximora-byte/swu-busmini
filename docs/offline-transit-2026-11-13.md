# 静态公交导航

默认入口 `pages/journey/journey` 使用享坐车西南大学静态资料，支持按上、下车参考点查询，或从当前位置选择800米内最多六个候车候选，给出直达与一次换乘方案。地图显示本次乘车区间与上下车点，可打开站点地图查看实际位置。旧的2025图示页可从“历史图示”访问，两套数据不混用。

现支持[本地模糊搜索、地图选点与自动乘降推荐](transit-search-2026-11-13.md)：确认出发／到达参考位置后，联合选择附近可达的上下车点；也保留精确指定站点。

## 来源与质量

2026-11-13 从用户正常打开的享坐车小程序读取其已加载的静态资料，共十线、162个站点节点、103个精确名称／坐标身份、682个轨迹点。用户确认线路准确并授权获取；成功采集没有使用或保存账号凭证，没有保存整份进程数据或原始会话。提取字段仅覆盖静态线路、站点和几何。

两类源数据先按来源线路身份配对，再移除内部标识。部分旧字段夹带外地占位坐标，未用于导航；采用小程序实际绘制的西大轨迹。坐标系按微信地图消费者定义为GCJ-02，质量为 `operator_published`，不冒称实地校准。

站点数组存在与真实几何里程不同的排列，因此按原客户端的方法投影到对应轨迹再排序，同时保留sourceIndex。方向是沿公布几何的正反里程，未取得独立的上下行车道或运营方向证明；导航卡通过“先经某站”提示，并明确要求现场核对。复核确认6／7／8存在引入段和中段近闭环图形，不能据此推定可连续循环或回走引入段，程序不创建跨回接点的运营边。详见[方向与闭合复核](direction-closure-check-2026-11-13.md)。

3B的“2号门”与发布轨迹偏移约83米，地图保留原始位置并标记待核对；当前暂不作为3B的自动上下车和换乘点，同站在3号线仍可用。超过35米会提示并隔离自动乘降，超过150米或不在北碚坐标范围时导入失败；这不是实际停站结论，也没有移动原坐标或借用其他线道路。

## 站点与规划规则

- ID由原文名称与六位小数坐标共同产生；不同名称、同名异点和近邻点不会模糊合并。103个ID不代表已经确认103个不同实体站台，只表示数据中103个精确身份。
- 换乘仅连接同一个精确身份且该线路的visit满足自动乘降策略，不猜测横穿道路或跨站步行换乘。相近同名记录仍可各自作为位置候选，页面只附加满足策略的线路说明。
- 每次经过保留站序索引、原始索引与轨迹锚点，正反向裁剪以出现位置为准，不按站名搜索第一个匹配点。
- 每腿至少超过1米且上下车身份不同；不生成零长乘车或同线路换乘，不自动添加环线闭合边。
- 排序按换乘次数、接驳直线距离、乘车里程，最多六项。不预测速度、等待、班次或到站时间，也不声称最快。
- 当前位置只在用户主动请求时读取，保留在本次页面内存，不写入源数据或上传。重新定位会立即清除旧定位起点；失败、取消或离开页面后显示表单中的手动站点，不静默复用上次坐标。定位拒绝、超时、校外远点不会阻止手动选站。
- 接驳距离是直线距离；站点地图可用于进一步选择实际道路，程序没有把两点连线当作步行路线。

## 可重现的数据流程

`miniprogram/data/current-transit-source.json` 是去标识化的发布资料：只含内部线路ID、公开名称、颜色、站点坐标、实际绘制点与来源日期。`current-transit.json` 和 `.ts` 为确定性导入结果，运行时只加载TS。

```sh
npx tsx scripts/import-current-transit.ts --check
npm run sync:data
npm run check:data-sync
npm run validate:data
npm run typecheck
npm run test:coverage
```

`scripts/current-transit-data.ts` 对公开源执行字段白名单、范围、真实日期、轨迹投影和身份校验；Repository再次校验来源质量、引用、锚点与里程并返回副本。全量原始静态资料、解包产物、采集工具和验证记录保留本地，不属于仓库上传内容。公开版本不包含来源内部线路／学校／站点标识、账号、令牌、个人记录、车辆记录、接口地址或本机绝对路径。校园公共坐标是导航所需事实，不作个人位置上传。

## 验收边界

合成与真实资料测试覆盖正反向、一次换乘、精确身份隔离、重复经过、区段裁剪、附近次近站可达、服务范围、定位失败和异步覆盖。WXML／WXSS由微信工具编译器检查；后续[开发者工具核验](devtools-navigation-qa-2026-11-13.md)实际观察了地图、上下车／换乘标签、选站、卡片和游客定位，并修复换乘标签被裁剪的问题。真实GPS、授权流程、外部站点地图和后台恢复仍需真机验收。实时数据的可用边界见[接入评估](realtime-source-assessment-2026-11-13.md)。
