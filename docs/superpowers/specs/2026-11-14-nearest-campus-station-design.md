# 点选位置，导航到最近校车站

用户已明确选择以手机当前位置为步行导航起点。点选地图位置只用于推荐附近站点，不把它冒充原生导航起点。采用微信内置地图查看站点并由用户选择步行方式；不用新增插件、密钥或付费路线请求。相比接入步行WebService，这种方式复用现有能力；不自行把两点直线绘为步行道路。

普通地图空白点选显示最多三个不同站区，按距所选点的直线距离排列，优先最近一个。每个站区选择其中最近且具有可用线路的原始乘降点，不使用可能待核对的展示中心。仅检索800米内当前校车资料，空结果明确提示，不回退到任意站点。距离不能称为最近步行距离或ETA。

显式“改起点／选终点”模式优先，普通附近查站不修改现有起终点或所选行程。地图显示所选点与推荐站，关闭后恢复此前线网／乘车方案。可继续查看站点的两个参考方向。导航只能从当前有效推荐项发起，重复点击、失败、关闭、切线和页面隐藏都须正确清理待处理状态。

不新增定位采集或持久化，不改变原始站点、轨迹和隐私配置。真实手机地图内的路线模式与权限行为仍须真机核验；开发工具模拟不冒充后台或手机验收。
