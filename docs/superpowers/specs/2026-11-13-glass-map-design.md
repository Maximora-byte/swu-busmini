# 地图优先的玻璃浮层首页

用户要求合并PR11，并把校园地图／出行规划进一步融合成类似高德的交互，采用液态玻璃风格，尽量美观、流畅。PR11已合并；本变更在其基础上继续迭代体验版，不自动合并后续PR或正式发布。

采用常驻全屏地图、顶部搜索入口、侧边地图工具和底部三档浮层。地图浏览和路线规划是同一地图上的内容状态，不再展示两个大页签。线路选择／站序和搜索／起终点／方案都在浮层内完成，原有端点及方案可恢复。

视觉使用浅色通透底、细边缘高光、柔和阴影和原生导航浅色背景；小面积搜索框／工具按钮可渐进增强模糊，浮层主体保留高对比浅色底，不做持续折射或大面积模糊动画。所有数据、图标为自有代码／现有资料，不复制高德资产。模糊不可用时仍清晰可用，不宣称原生iOS液态玻璃或保证所有真机帧率。

浮层收起／半展开／展开三档。拖动柄在WXS渲染层更新transform和局部滚动高度，移动过程中不callMethod、不setData、不重新发送几何；松手后才提交一个合法档位。提供按钮作为无手势替代，取消／多指／过时拖动不能覆盖新状态。底部保留原生地图版权标识及安全区，滚动区按实际可见高度计算。

地图视野适配需避开顶部搜索和浮层；完全展开时暂停自动适配，收起后再适配，避免上下车点被遮住。定位、地图选点、选站、方案切换的已有过时回调保护保留。地图点击仅在明确选点状态提交；选择／定位后展示紧凑推荐卡，详情和起终点编辑在浮层展开后查看。

首次不预填示例起终点，不自动请求定位。两个端点需明确选择或主动定位确认后才规划。定位失败只回退到已确认的公布站点；没有可回退站点时保留未确认状态，不能偷偷用默认第一个站。搜索修改和地图起点会使旧站点回退失效。

数据源、103个身份／162个visit／682个点、35米隔离、800米／六候选、精确身份换乘、无实时和不补闭合边均保持不变。原生地图底图不做付费个性化配置，不新增后端、Key、权限或个人数据持久化。AppID仅在本机候选配置。

验证包括纯布局／遮挡留白、WXS手势边界与每帧零逻辑桥调用、未确认端点和安全回退、浮层状态与导航流程、窗口／键盘变化、旧入口兼容。实际AppID模拟器检查覆盖物层级、点击穿透、地图操作和多档截图；真实手机的模糊效果、键盘及帧率如未验证需明确记录。
