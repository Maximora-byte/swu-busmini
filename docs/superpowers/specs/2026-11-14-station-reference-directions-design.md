# 两个参考方向

用户明确选择“先做两个参考方向”。相近站点不再展开每条源记录，保留两个紧凑方向入口与途经线路标签；实际站位、运行方向仍需现场核对。

展示归拢采用同名（含已知“共青花园／共青团花园2号门”别名）、组内任意两点不超过80米的站区；使用原始点中的中心点，不新造两侧坐标。较远同名点和不同楼号不合并。地图每站区一个入口，详情最多两个方向。

方向取发布轨迹在停靠投影段的局部轴线。各线路按与轴线的同向／反向关系对齐，不能直接把不同线路的正序统称同向。近垂直分岔不强行归类，可看线路或自动规划。方向只称参考A/B，以参考经由站辅助区分。

方向操作把原始route/visit/direction限制传给规划器，同时约束直达首尾、换乘首腿与末腿；待核对点不进入限制，普通选点仍自动比较线路。编辑一个端点仅清除它的方向选择，交换端点交换限制。原始站点、162次经过、轨迹与换乘身份不变。
