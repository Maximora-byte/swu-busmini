# 统一校园站点

按用户提供的高德站点详情参考，把重复图钉收敛为站区入口，并展示途经线路。沿用现有地图和玻璃浮层，不新增页面或权限。

仅展示层归拢同名、组内任意两点距离不超过20米的记录，防止邻近链条扩大站区。以原始点中的距离总和最小点作为展示锚点，不新造坐标。同名较远点分站区；不同名字不自动合并。原始站点、站序、坐标、规划换乘规则不变。

候选方案：直接改写源数据会丢失路线身份；只隐藏重复图钉无法查看途经线路；采用独立展示分组和统一详情卡，保留每条线路的原始记录和隔离状态。这是针对所给参考的实现选择。

点击图钉显示站名、发布线路、参考相邻站和乘降操作。通用起终点操作按站区坐标交给现有规划器自动比较；线路记录操作使用原始站点，待核对记录禁用。参考站序不宣称实际方向；无实时到站、票价或班次信息。

验收：地图去重、同名远点保留、链式邻近不串联、重复经过保留、路线隔离不被分组解除；切线/规划/返回后卡片状态不残留。
