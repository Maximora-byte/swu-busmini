# 享坐车线路资料与图示导航的适用范围

2026-11-13 在正常运行的享坐车微信小程序（`wxcbd5ca006d4d86f0`，367版）选择西南大学，逐线查看首页地图。用户确认该小程序线路准确，并授权用于改进 SWU Go。

本次记录十个线路入口：1～8号线、3路B线、经管专线，共162个跨线路显示的参考点名称。只保存可见线路名称和参考点原文；没有复制发布包代码或素材、个人缓存、凭证、车辆位置，也没有重放后台接口。

| 数据 | 用途 | 边界 |
| --- | --- | --- |
| `operator-routes.json` / `.ts` | “当前线路”离线目录，来源、日期、用户确认范围 | 参考点集合；没有有向站序、坐标、时刻或实时车辆信息 |
| `routes.json` / `.ts`、`stops.json` / `.ts` | 2025图示参考站序、方向、OD与一次换乘匹配 | 保留已有来源和待审核状态，未因目录确认自动升级 |
| `route-geometries`、`route-preview` | 审核轨迹与明确标记的腾讯参考片段 | 继续执行原有门禁，不为3B和经管专线拼接旧线轨迹 |

“中心图书馆地科院”“共青花园、2号门”等组合名称保持原文，不自动拆站；“梅园”“梅园1舍”也没有按相似名称自动合并。显示顺序不作为行车方向或站序的证据。当前线路目录与导航仓库隔离，因此新增目录条目不会生成直达或换乘建议。

当前页面没有9路入口。这仅证明本次观察未列出它，不代表停运。2024-04-14学校宣传部转载的[校园开放日资料](https://dwxcbwlgzb.swu.edu.cn/info/1028/4512.htm)曾列出9路，属于历史线索，不作为2026年的运营证明。2024-11-28[夜间专线通知](https://www.swu.edu.cn/info/1066/11387.htm)也具有当时的试运行范围，不直接写入当前日间线路与时刻。

后续取得完整有向站序、真实候车点和线路轨迹后，应先登记来源，逐项建立站点身份对应，再按现有数据审核流程更新导航资料；不能仅按本次标签数组的顺序生成 `stopIds`。

维护目录后运行 `npm run sync:data`、`npm run check:data-sync`、`npm run validate:data`、`npm run typecheck` 和 `npm run test:coverage`。Repository 在运行时校验字段、真实日历日期、重复线路ID和参考点，并返回防御副本。

本次地图交互保留统一选线入口和相机版本保护，新增稳定站点marker身份及点选反馈。未引入享坐车的双地图、固定延迟清空或车辆接口。自动化测试模拟地图API，尚需微信真机检查窄屏布局、label点击、定位、进后台恢复及快速切线后的原生地图显示。
