# 地图点选与最近校车站导航

用户选择手机当前位置作为步行导航起点。使用方式：

1. 点击地图空白处，查看所选位置800米内最多三个不同站区，最近项排在首位。
2. 点击“站点与方向”查看参考方向，关闭后返回附近站点列表。
3. 点击“导航去车站”，打开微信地图中的站点位置，再选择步行方式；导航从手机当前位置出发。

点选位置仅用于找站，直线距离不是步行距离或到站时间。每个站区选择其中最近且有可用线路的原始乘降记录，导航目标不是站区展示中心。路线名称仅列出该原始记录的可用线路，保留3B等线路级隔离。800米内无可用记录时显示空结果，不替用户选择默认站。

普通点图不修改既有行程和端点；关闭附近站点后恢复原乘车方案或线网视野。明确的“改起点／选终点”模式仍优先用于公交规划。重复导航点击、失败、过期回调、页面隐藏和异步地图恢复都有回归。

本功能复用既有微信内置地图能力，不新增密钥、插件、定位请求或付费路线调用，也不保存用户位置。地图内真实路线模式与手机权限仍由用户在原生地图中决定；本地交接测试不代表真机地图、后台权限或微信审核验收。

验证：安装、同步、数据、TypeScript及完整覆盖率运行通过，共348项测试；最终候选完成19组开发者工具回归，包含真实点击附近列表、站点详情及导航按钮。原生地图交接与定位异常使用开发工具会话内合成输入，模拟API已恢复。独立复核发现的恢复视野竞态已修复并加入延迟渲染回归。
