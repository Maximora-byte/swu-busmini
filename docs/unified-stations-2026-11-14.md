# 统一站点与途经线路（0.1.6基线）

后续已按用户选择精简为[两个参考方向](station-reference-directions-2026-11-14.md)；下文保留0.1.6的核验记录。

地图把103个发布记录显示为53个站区入口，其中25个入口包含多条原始记录。162次线路停靠记录全部保留，原始数据文件、坐标、线路轨迹和规划换乘规则没有改写。

归拢规则为同名且组内任意两点距离不超过20米；不是传递性距离聚类。同名远点标注不同站区，不同名称不自动归拢。展示锚点取已有坐标中的中心记录。该规则用于地图阅读，不能证明这些记录是同一实际乘降点。

点击站点，玻璃浮层显示途经线路及发布参考相邻站。可以查看线路、从站区出发或到站区去；通用站区操作通过现有坐标规划器比较附近线路，单条记录操作使用原始站点身份。每条记录保留可乘降状态，3B偏移点仍禁止自动乘降，重复经过记录也不丢失。相邻站为几何参考顺序，未据此认定实际方向。

地图聚焦为详情卡保留可见区域；短屏使用单点聚焦留白，网络总览适配规则不变。卡片关闭、切换线路及进入规划后清除旧详情。当前没有实时车辆、到站预测或票价资料。

验证：

- `npm ci`、`npm run check:data-sync`、`npm run validate:data`、`npm run typecheck`、`npm run test:coverage`。
- 329项测试通过，包括分组完整性、距离链条、异名同点、同名远点、隔离记录、重复停靠、原始点操作及559/480像素短屏聚焦。
- 微信开发者工具实际编译及挂载：53个地图入口，统一站点卡片显示途经线路，实际点击线路按钮可切线，待核对记录操作不改变起点。
- 开发者工具验证使用公开校园参考位置；没有触发真实定位、原生选点或隐私授权。模拟器核验不代表手机真机验收或微信审核通过。
