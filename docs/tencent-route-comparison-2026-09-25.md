# 腾讯导航参考线与 2025 校园地图比对（2026-09-25）

## 范围与证据

依据用户提供的《西南大学北碚校区校园地图（2025）》左上角线路表核对站名、顺序、环线结构和识别色。本次使用会话中的图片；原本地高清图片路径已不可读，因此没有声称重新检查高清原图。未从图片像素推算任何经纬度，也未进行几何配准。

1～9 路现有站序与图中可辨认文字一致；4 路第二站保持“二食堂”，1 路为“经管院 → 六号门 → 二号门 → 八教 → 田家炳 → 圆顶 → 五号门”。6～9 路保留闭环，6/9 路保留中途重访二号门。“中图”为中心图书馆采用用户此前确认。没有修改 routes、stops、正式坐标审核或正式轨迹数据。

腾讯地点搜索只在北碚区查询，使用西南大学上下文和规范化精确名称匹配，拒绝模糊首条结果及多义匹配。取得唯一候选后，按现有方向站序请求相邻两点的腾讯驾车导航，并缓存各方向结果。API 只提供道路参考，不证明校车实际走这条道路。

接口：[腾讯地点搜索官方文档](https://lbs.qq.com/service/webService/webServiceGuide/search/webServiceSearch)，`/ws/place/v1/search`；驾车导航使用已有适配器 `/ws/direction/v1/driving/`。

## 对比发现与处理

- 早期地址地理编码将六号门落在校园中部附近；本次采用腾讯明确标题“西南大学-6号门”的候选，位置在经管院一带，与图片相对布局一致。
- 早期 26 教候选偏到校园西南远处；本次明确“26教学楼”搜索匹配后回到梅园附近。外语院候选同样纠正至地科院周边。以上是相对布局检查，不是现场坐标确认。
- 二号门、五号门通过各自明确校门标题取得不同候选，不再接受早期多个站名落在相同地理编码坐标的结果。
- 圆顶搜索返回“圆顶报告厅”，但该别名对应关系尚待人工确认，没有自动等同。
- 西师街搜索出现商户，未获得可靠同名道路/站点候选。
- 二食堂搜索出现“楠园1食堂”等其他食堂，明确不采用，也不把线路站名改掉。
- 大礼堂出现“礼堂”“八一礼堂”等结果，尚不能确定线路表所指，保留空缺。

仍需人工提供：圆顶、西师街、二食堂、大礼堂的明确地点/腾讯位置分享，及实际乘车轨迹或关键转弯点。尤其应核对腾讯推荐道路是否允许校车通行、有无校园内部道路遗漏；当前无法保证与示意图片逐路段重合。

## 地图选择行为

点击某号线会关闭路网总览，仅显示该线当前方向，自动调整视野并保留用户位置。方向按钮常驻；当前线路、方向、覆盖段数与待审核提示可见。手动开启总览才会叠加其他线路；从导航结果或换乘分段打开线路同样进入单线模式。

小程序读取本地 TS Adapter，不实时请求腾讯 API。Key、本地请求缓存与原始请求 URL 不提交 Git。
