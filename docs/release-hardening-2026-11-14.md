# 0.1.9 小范围发布加固

本次只补全错误兜底、整理端点转换和增加实际包体证据门禁，没有全面重写页面、WXML或规划算法。

## 错误恢复

App注册运行时错误、未处理拒绝和页面缺失钩子，跳转不依赖路线数据的恢复页。恢复仅使用固定原因类别与固定首页路径，不记录／存储／透传原始异常、搜索、坐标、路径或凭证，也不增加遥测。并发／递归恢复、导航失败、离开恢复页后的延迟回调和后续再次出错都有回归。

恢复成功后可以再次捕获错误；页面销毁后不会更新旧页面。模块加载异常的原生派发由单元测试模拟；模拟器另验证了真实异步异常、真实未处理拒绝和恢复页重试。此范围不包括App尚未注册时的引擎致命故障或真机全部异常时序。

## 端点模型

新增纯EndpointState读取、转换、平面视图适配与交换函数，page.data继续是唯一可变来源，既有界面字段和页面API保持兼容。统一编辑、精确站点、地点、地图点及无坐标指南的状态提交；起点特有定位回退、消息、方向约束和版本取消语义保留，不引入事件总线或第二份可变状态。

## 实际包体

官方开发工具预览回执实测273,473字节，低于项目内部512KiB预算。脱敏证据在release/package-size.json；源码／配置指纹变化或回执缺失、非法、超过预算都会使检查失败。工具失败但退出码为0、未生成回执的情况不能放行。

记录器核对私有候选与staged输入，规范化文本换行，只允许候选替换AppID，并去除回执中的二维码、路径、账号等非大小数据。CI无需微信凭证，验证已捕获官方构建证据及输入指纹，不独立运行官方编译器、认证回执或承诺平台限额；512KiB不是平台限制声明。详见release/README.md。

## 验证与边界

- npm ci、数据同步、数据校验、TypeScript、完整覆盖率：374项测试通过。
- 22组开发者工具回归：19组原有地图／站点／规划／导航交接场景，以及3组恢复场景。地图定位／选点输入为本机会话内合成值，未代用户授权；原生外部缺失路径派发和真机行为没有据此验收。
- 独立整体审查未发现剩余P0—P3实质问题；实际构建证据随后单独校验通过。
- 原始数据、隔离门禁、隐私配置与依赖不变。正式候选、二维码及截图保留本机，公开配置保持游客模式。

上传与体验／审核状态以官方回执或用户明确确认为准，不将预览、CI或开发工具测试等同微信审核通过。
